# CampusNotes
Student Note-Sharing Portal — Anshu Raj (2581060)

## Usage

Open `index.html` in a browser to use the keyword-search interface. The page loads `search.js` and filters the sample notes by unit title or keyword. You can also reuse `searchNotes(list, query)` from `search.js` in another JavaScript file.

## Project files

- `index.html` — CampusNotes page with a search input and live result list.
- `search.js` — reusable keyword-search helper.
- `notes.txt` — sample unit notes.
- `.gitignore` — ignores temporary `*.log` files.
