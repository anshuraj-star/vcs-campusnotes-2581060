# Notes Layout

This branch records a simple layout plan for the CampusNotes study material.

## Units

1. Git Basics
2. Branching
3. Merging
4. Remote Repositories

## File organization

- Keep short unit summaries in `notes.txt`.
- Keep the searchable note titles in the CampusNotes page.
- Keep reusable search behavior in `search.js`.

This branch is intended to demonstrate a separate notes-layout branch alongside `main`.
